Для сбора траффика нужно запустить скрипт в текстовом документе под линукс (или под виртуалкой на линукс).
Трафик собирается в файл .pcap и просматривается в wireshark
Запросы и ответы дописываются в файл gruyere_traffic.json (если файла не было, он будет создан при первом запуске скрипта)
Также в скрипт добавлено разархивирование.
