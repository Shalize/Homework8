Для сбора траффика нужно запустить скрипт в текстовом документе под линукс (или под виртуалкой на линукс).
Трафик собирается в файл .pcap и просматривается в wireshark
Запросы и ответы дописываются в файл gruyere_traffic.json (если файла не было, он будет создан при первом запуске скрипта)
Также в скрипт добавлено разархивирование.

В файл gruyere_traffic.json сохранены запросы и ответы удачных (и не очень, т.к. были без разархивирования gzip) запусков скрипта.
Запись от 00:46:28 удачная со срабатыванием скрипта XSS в сниппете на сайте google gruyere.
То есть:
в обычном трафике есть запись "request": "GET /417051499941739605858883565399756726567/newsnippet2?snippet=11 HTTP/1.1", в то время как в трафике с xss запись выглядит следующим образом: "request": "GET /417051499941739605858883565399756726567/newsnippet2?snippet=%3Ca+onmouseover%3D%22alert%281%29%22+href%3D%22%23%22%3Eread+this%21%3C%2Fa%3E HTTP/1.1" .
Добавлено изображение срабатывания эксплойта (эксплойт был в сниппете, <a onmouseover="alert(1)" href="#">read this!</a>).
Для предотвращения подобной атаки нужно включить атрибут onmouseover в файл с кодом для очистки от исполняемого кода в комментариях или добавлении сниппетов.
